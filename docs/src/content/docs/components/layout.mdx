## What it's for

To give a page its shape from spacing tokens, without a media query. They look at the room they have, so the same page works in a window, a column or a side panel.

## When not to use it

- **Inside an article.** For peers in running text, use [columns](/components/columns/).
- **A one-off with a real reason.** Write the CSS. These cover the common cases, not all of them.

## Anatomy

- **Stack:** one above the other, one gap.
- **Cluster:** a row that wraps.
- **Grid:** equal columns that wrap by `min`. A child with `class="span-all"` takes the whole row.
- **Split:** a narrow side and a wide main, which stack when both no longer fit.

## Variants

| Prop | On | Does |
|---|---|---|
| `gap` | All | A step of the spacing scale, 1 to 10. |
| `min` | Grid | The narrowest a column can be, in px. |
| `justify` | Cluster | `start`, `between` or `end`. |
| `side`, `main`, `sideAt` | Split | Widths in px, and which side the narrow one is on. |
| `as` | Stack, Cluster, Grid | The element to render. |

## States

It has no states of its own.

## Tokens

`--sp-1` to `--sp-10`.

## Keyboard and screen reader

- **They add no roles.** Pass `as` when the group means something, such as `as="ul"`.
- **Reading order is source order.** `sideAt="end"` moves Split's side visually, so check the order still reads.

## Content

- **They hold no text of their own.**

## Status

New. Used by a dashboard.

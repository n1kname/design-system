Plot has no arc mark, so this one is drawn with d3-shape.

## Keep in mind

- **Labels are HTML, not SVG text.** Text inside an SVG shrinks with the column. A list keeps its real size.
- **`alt` speaks for the whole chart.** The ring and the list are hidden from screen readers, so `alt` needs every value.
- **Every slice needs its own slot.** Otherwise you can't match a slice to its label. Grey slices only work when you don't need to tell them apart, and that's rarely true.
- **Slices keep the order you give them.** It starts at 12 o'clock and runs clockwise, so sort first if you want largest first.
- **Six slices is a good limit.** Past that, bars usually read better.

## What it's for

For showing a few parts of a whole at a glance.

## When not to use it

- **Close values, or more than six.** Use [ranked bars](/components/ranked-bars/).
- **Values that don't add up to a whole.**

## Anatomy

- **Frame:** a [figure](/components/figure/) on a plate.
- **Ring:** drawn with d3-shape, because Plot has no arc mark. Starts at 12 o'clock and runs clockwise.
- **Title:** in the middle of the ring.
- **List:** the labels and values, in HTML, so they keep their real size when the column shrinks.

## Variants

`strong` per slice sets its label in bold.

## States

It has no states of its own.

## Tokens

`--c-border`, `--c-chart-1`, `--c-surface`, `--c-surface-sunken`, `--c-text`, `--c-text-muted`, `--font-display`, `--font-mono`, `--layout-measure`, `--leading-body-sm`, `--leading-caption`, `--leading-sub`, `--radius-lg`, `--sp-1`, `--sp-2`, `--sp-3`, `--sp-4`, `--sp-5`, `--sp-6`, `--text-body-sm`, `--text-caption`, `--text-mono`, `--text-sub`.

## Keyboard and screen reader

- **One image to a screen reader.** The ring and the list are hidden, so `alt` needs every value.

## Content

- **Every slice needs its own slot,** or you can't match a slice to its label.
- **Slices keep the order you give them,** so sort first if you want largest first.

## Status

Used by the portfolio. The case it was built for now uses ranked bars. It stays for the next one that needs it.

## Code

```astro wrap
---
import Donut from '@n1kname/components/Donut.astro';
---

<Donut
  title={['Fictional', 'shares']}
  alt="Say what the chart shows, including the values."
  caption="Optional."
  data={[
    { label: 'Alder', value: 24, valueLabel: '24%', color: 'var(--c-chart-1)', strong: true },
    { label: 'Birch', value: 21, valueLabel: '21%' },
  ]}
/>
```

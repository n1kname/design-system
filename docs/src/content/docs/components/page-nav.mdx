## What it's for

To move between the handful of pages a site has, and to show which one you're on.

## When not to use it

- **More than about eight pages.** Then it needs grouping, which this doesn't do.
- **Within a page.** Sections of one page are headings, not navigation.
- **More than once on a page.** The pill's transition name must be unique.

## Anatomy

- **List:** links in a row that wraps.
- **Current link:** `aria-current="page"`, in the body text colour and semibold.
- **Pill:** an empty shape behind the current link's text. It is a shape of its own so it can move without the words.

## Variants

None.

## States

- **Hover:** the text darkens, on a soft surface.
- **Current:** the pill.
- **Changing page:** with `page-change.css`, the page cross-fades over `--motion-base` and the pill glides to its new place on the spring. A browser without cross-document view transitions simply changes the page.
- **Reduced motion:** the page changes at once.

## Tokens

`--c-border`, `--c-focus`, `--c-surface`, `--c-surface-hover`, `--c-text`, `--c-text-secondary`, `--ease-hover`, `--ease-out`, `--ease-spring`, `--leading-body-sm`, `--motion-base`, `--motion-hover`, `--motion-spring`, `--radius-md`, `--sp-1`, `--sp-2`, `--sp-3`, `--text-body-sm`.

## Keyboard and screen reader

- **A `nav` with a name,** "Pages" unless you pass `label`, so it can be found among the landmarks.
- **The current page is announced** through `aria-current`.

## Content

- **One or two words a page,** the same words as the page's title where possible.

## Status

New. Taken from a dashboard's header.

## Code

```astro wrap
---
import PageNav from '@n1kname/components/PageNav.astro';
import '@n1kname/components/page-change.css';
---

<PageNav items={[{ href: '/', label: 'This year', current: true }, { href: '/costs/', label: 'Costs' }]} />
```

## Keep in mind

- **Import `page-change.css` on every page,** once. Both the page you leave and the one you arrive at must opt in.
- **Mark the current page yourself** with `current`.

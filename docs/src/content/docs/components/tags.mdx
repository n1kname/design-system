## What it's for

To label something in a word or two. A tag and a link are the same object here, so the fill says which one you're looking at.

## When not to use it

- **The main action in a view.** Use a [button](/components/buttons/).
- **A state that needs attention.** A status needs an icon and words, not only a colour.
- **Long labels.** It doesn't wrap.

## Anatomy

- **Icon:** optional, only where there's a real taxonomy.
- **Label:** one line.
- **Fill:** set by the tone.

## Variants

| Tone | Means |
|---|---|
| `accent` | A link you can act on, or a live state. |
| `quiet` | A descriptor, not something to click. |
| `warm` | How something was done. |
| `cool` | What something was about. It uses the same teal as the second chart colour. |

`small` works with any tone.

## States

Without `href` it has no states, so it can't look clickable by accident. With one: hover deepens the edge and the fill, under a real pointer it lifts 2px, a press gives a little, and the spring brings it back. Focus shows the ring. `still` turns the lift and press off, for a tag inside something that moves as a whole, such as a [copy tag](/components/copy-tag/). Under reduced motion it doesn't move.

## Tokens

`--c-accent-edge`, `--c-border`, `--c-border-strong`, `--c-surface`, `--c-surface-tint`, `--c-tag-cool-bg`, `--c-tag-cool-text`, `--c-text`, `--c-text-accent`, `--ease-spring`, `--motion-spring``--c-text-muted`, `--ease-hover`, `--motion-hover`, `--radius-full`, `--sp-2`, `--sp-3`, `--text-body-sm`, `--text-caption`. `--c-tag-focus-*` still works as an old name.

## Keyboard and screen reader

- **With `href` it's a link, without it a plain span,** so assistive tech gets the right thing.
- **The icon is hidden from screen readers,** so the label has to say it all.

## Content

- **A word or two,** in sentence case.
- **Put warm tags on a page or a card, not on a sunken plate.** The tint nearly matches the plate, so the fill disappears, though the text still passes.

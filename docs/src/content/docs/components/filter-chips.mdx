## What it's for

To filter what a page shows to one value of a few to a dozen: an activity, a category. Each chip says how many items it has, so a choice that would show nothing is visibly empty before anyone presses it. With a [Search field](/components/search-field/), the counts follow the search.

## When not to use it

- **Two to four fixed options without counts,** such as Top 20 / 50 / 100. Use [Segmented](/components/segmented/).
- **Choosing several at once.** These choose one.
- **Dozens of values.** Search instead.

## Anatomy

- **All,** first, with the total (leave out `all` for none).
- **A chip per value:** a swatch in its colour, its name and its count.

## Variants

- **With or without counts,** by giving `count` or not.
- **With or without swatches,** by giving `color` or not; without, a chip tints in the accent.

## States

- **Chosen:** a tint and a border of the chip's own colour, the name in bold, the swatch a little larger. Never an inverted fill: a whole row of chips stays calm.
- **Hover:** a fainter tint of the same colour.
- **Empty** (a count of 0): disabled, unless it is the one chosen.
- **Changing:** the states fade into each other over `--motion-base`; the swatch grows on the spring. In place under reduced motion.

## Tokens

`--c-accent`, `--c-border`, `--c-focus`, `--c-surface`, `--c-text`, `--c-text-muted`, `--c-text-secondary`, chart tokens for `color`, `--ease-out`, `--ease-spring`, `--motion-base`, `--motion-spring`, `--sp-1`, `--sp-2`, `--sp-3`, `--text-caption`.

## Keyboard and screen reader

- **A group named by `label`** of pressed and unpressed buttons. Tab reaches each.
- **A second press on the chosen one** goes back to All.

## Content

- **Names as on the rest of the page,** and counts as plain numbers.

## Status

New. Taken from a dashboard's Places and Workouts pages.

## Code

```astro wrap
---
import FilterChips from '@n1kname/components/FilterChips.astro';
---

<FilterChips id="kinds" label="Activity" />

<script>
  import { setChips } from '@n1kname/components/chips.js';
  const chips = document.getElementById('kinds');
  setChips(chips, [{ value: 'cycling', label: 'Cycling', color: 'var(--c-chart-3)', count: 312 }, …], 'all');
  chips.addEventListener('chips-change', (e) => show(e.detail.value));
</script>
```

## Keep in mind

- **Call `setChips` again with new counts;** with the same values it only updates the counts and states, so focus stays put.

## What it's for

To show the order things happened in. The last entry is the current state, so its marker looks different.

## When not to use it

- **Steps someone has to follow.** Use a numbered list.
- **A long history with no turning points.** Say it in a sentence.

## Anatomy

- **Period:** mono, in an 84px column.
- **Label and body:** what happened.
- **Line and marker:** the last marker is filled.

## Variants

None.

## States

It has no states of its own.

## Tokens

`--c-accent`, `--c-bg`, `--c-border`, `--c-text`, `--c-text-muted`, `--radius-full`, `--sp-1`, `--sp-4`, `--sp-5`, `--sp-6`, `--sp-7`. Needs `type.css`.

## Keyboard and screen reader

- **It's an ordered list,** so screen readers announce how many entries there are.
- **The line and markers are decoration,** so the period has to say when.

## Content

- **Keep periods short,** about 11 characters.
- **Say what changed,** not what the team did.

## Status

Used by the portfolio.

## What it's for

To help someone find a thing they already know by name. [Lucide](https://lucide.dev/) paths, inlined: no package, no webfont, no extra request. Only the icons in real use are here, and adding one is a single line in `icons.ts`.

## When not to use it

- **Decoration.** Decorative icons are worse than none.
- **On its own, without a label,** unless the control has an `aria-label`.

## Anatomy

- **Path:** from `icons.ts`.
- **Size:** set by `size`, in px.
- **Stroke:** thins to 1.75 below 20px, because Lucide is drawn at 24px and reads heavy when small.

## Variants

None.

## States

It has no states of its own.

## Tokens

It takes the colour of the text around it, so it uses no tokens of its own.

## Keyboard and screen reader

- **Hidden from screen readers,** so the label beside it has to say what it means.

## Content

- **One icon per meaning,** so the same picture never means two things.

## Status

Used by the portfolio.

## Keep in mind

- **Below 20px the stroke thins to 1.75.** Lucide is drawn at 24px with a stroke of 2, which reads heavy when small.
- **It takes the colour of the text around it,** and it's hidden from screen readers, so the label beside it has to say what it means.

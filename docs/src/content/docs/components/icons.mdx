## What it's for

To help someone find a thing they already know by name. [Lucide](https://lucide.dev/) paths, inlined: no package, no webfont, no extra request. Only the icons in real use are here, and adding one is a single line in `icons.ts`.

## When not to use it

- **Decoration.** Decorative icons are worse than none.
- **On its own, without a label,** unless the control has an `aria-label`.

## Anatomy

- **Path:** from `icons.ts`.
- **Size:** set by `size`, in px.
- **Stroke:** thins to 1.75 below 20px, because Lucide is drawn at 24px and reads heavy when small.

## Variants

| Option | For |
|---|---|
| `draw` | The icon draws itself in once, line by line, as it arrives. Inside a [Reveal](/components/reveal/) it draws when that Reveal arrives, on its beat; outside one, as it comes a third into view. Icons that arrive together go 110ms apart. |

## States

- **Drawing** (`draw` only): hidden once the script has armed it, then each line is drawn on over `--motion-draw`.
- **Without script, or under reduced motion:** simply there.

## Tokens

It takes the colour of the text around it. Drawing uses `--motion-draw` and `--ease-soft`.

## Keyboard and screen reader

- **Hidden from screen readers,** so the label beside it has to say what it means.

## Content

- **One icon per meaning,** so the same picture never means two things.
- **Draw only where people look once,** such as a list of what someone does, or an empty page. Never in a toolbar, a row or anything used every day.

## Status

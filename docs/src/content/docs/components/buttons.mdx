## What it's for

To do something on this page. Give it an `href` and it becomes a link that looks like a button, for when the next step is somewhere else.

## When not to use it

- **Going to another place in running text.** Use a plain link.
- **A label you read but can't act on.** Use a [tag](/components/tags/).
- **Two primary buttons in one view.** Two of them means neither is.

## Anatomy

- **Label:** says what happens.
- **Fill and edge:** set by the variant.
- **Focus ring:** 2px, only when focus came from the keyboard.

## Variants

| Variant | For |
|---|---|
| `primary` | The one main action in a view. |
| `secondary` | Everything else, and the default. |
| `quiet` | Low-emphasis actions beside content. |

## States

| State | What changes |
|---|---|
| Hover | Darker fill on primary, accent edge on secondary, a tint on quiet. |
| Press | Scales to 97%, so you feel the click. Off with reduced motion. |
| Focus | A 2px ring. |
| Selected | A tint and an accent edge, and `aria-pressed="true"`. |
| Disabled | Half opacity and no press. WCAG exempts disabled controls from contrast, so explain why elsewhere if it isn't obvious. |

## Tokens

`--c-accent`, `--c-accent-edge`, `--c-accent-hover`, `--c-border-strong`, `--c-focus`, `--c-on-accent`, `--c-surface`, `--c-surface-hover`, `--c-surface-tint`, `--c-text`, `--c-text-accent`, `--c-text-secondary`, `--ease-hover`, `--ease-out`, `--font-body`, `--motion-fast`, `--motion-hover`, `--radius-sm`, `--sp-2`, `--sp-4`, `--text-body-sm`.

## Keyboard and screen reader

- **It's the real element,** so tab order, Enter and Space come from the browser. Never add a positive `tabindex`.
- **A toggle needs `selected` from the start,** `true` or `false`, so screen readers announce it as a toggle.
- **Target size:** 40px tall, 44px on touch screens. WCAG 2.5.8 asks for 24px.
- **Label on the primary fill:** the dark ink, 6.28:1 at rest. The fill against a light page is 2.92:1, which is fine, because WCAG 1.4.11 doesn't apply when the label alone identifies the button.

## Content

- **Start with a verb:** Save, Export, Show figures.
- **A link goes somewhere, a button does something.** Pick by what it does, not by how it looks.

Used by the portfolio. Also used by a dashboard.

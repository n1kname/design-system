## Families

One rule picks the family, so nothing has to be decided per component.

- **Bitter** marks a boundary: page titles, section breaks, card titles.
- **IBM Plex Sans** marks structure inside a component: sub-heads, labels, body.
- **IBM Plex Mono** marks data: years, IDs, values.

## Scale

Display sizes are fluid. Body and below are fixed, so reading size never moves.

<div className="not-content">

## Spacing

Four-based, ten steps, no exceptions.

The best motion goes unnoticed. It's there to give feedback or to show where something came from, never to decorate.

## Tokens

| Token | Value | For |
|---|---|---|
| `--motion-fast` | 120ms | Hover and press |
| `--motion-base` | 180ms | Small things appearing, such as a chart settling in |
| `--motion-slow` | 260ms | A panel, the largest thing that moves |
| `--motion-gentle` | 240ms | Hover on a portfolio |
| `--motion-reveal` | 900ms | The one opening of a portfolio page |
| `--ease-out` | `cubic-bezier(0.23, 1, 0.32, 1)` | Things arriving: fast start, soft landing |
| `--ease-exit` | `cubic-bezier(0.4, 0, 1, 1)` | Things leaving for good |
| `--ease-standard` | `cubic-bezier(0.2, 0, 0.38, 0.9)` | Things leaving that stay within reach, such as a side panel |
| `--ease-soft` | `cubic-bezier(0.16, 1, 0.3, 1)` | Long reveals: most of the travel comes early, so it answers at once |
| `--motion-spring`, `--ease-spring` | 340ms, a sampled spring | Experimental. Something arriving that should settle rather than stop, such as a panel |
| `--motion-hover`, `--ease-hover` | Fast and out, by default | What every hover uses. A site overrides these two, not each component |

## Spring, on trial

`--ease-spring` is a spring (stiffness 380, damping 24, mass 0.6) sampled into CSS `linear()`, so it needs no script. It covers most of the distance early, goes about 1.6% past the end and settles back, over `--motion-spring`. On a 24px slide that overshoot is under half a pixel: you feel it more than see it.

Open each panel and compare. The first is the side panel as it ships, on `--ease-out` over `--motion-slow`. The second only swaps in the spring for its opening.

## Two modes

Carbon calls these productive and expressive, and that split works here too.

| | Data pages | Portfolio |
|---|---|---|
| **Job** | Get out of the way | Set a mood, once |
| **Hover** | `fast`, `out` | `gentle`, `soft` |
| **Opening** | Nothing, data settles in over `base` | `reveal`, `soft`, about 70ms apart |
| **Page change** | Instant | A 180ms cross-fade |
| **Ambient** | None | Colour and grain on case heroes only, still |

A portfolio sets these once, and every component follows:

```css
:root {
  --motion-hover: var(--motion-gentle);
  --ease-hover: var(--ease-soft);
}
```

## Rules

- **Ask how often it happens.** Something you trigger all day should be instant. Tooltips don't animate for this reason.
- **Smaller things move faster.** A button is `fast`, a panel is `slow`.
- **Leaving is quicker than arriving,** and travels less. Your attention has already moved on.
- **One moment, then stop.** Charts settle in once when a page's data arrives, and not on every resize.
- **Move `transform` and `opacity` only.** Animating width or height makes the whole page work harder.
- **No looping motion to get attention.** No pulsing dots, no breathing buttons.

## Reduced motion

`tokens.css` cuts every animation and transition to almost nothing when someone asks their system for less motion. Anything that also moves, such as a press scale, turns that off in its own `prefers-reduced-motion` block, so the state still changes without the travel.
